# Glossary: Hands-On Machine Learning (3rd ed.)

**Activation function**: nonlinearity applied to a neuron's weighted sum (ReLU, GELU, Swish, sigmoid, tanh, softmax) (Ch 10–11)
**Adam / AdamW / Nadam**: adaptive optimizers (momentum + RMSProp); AdamW decouples weight decay; Nadam adds Nesterov (Ch 11)
**Advantage (RL)**: normalized discounted return of an action, or Q(s,a) − V(s) (Ch 18)
**Anomaly vs novelty detection**: find outliers in contaminated data vs flag new instances against a clean training set (Ch 9)
**Attention**: weighted sum of encoder outputs; weights from query–key similarity (Bahdanau additive, Luong multiplicative) (Ch 16)
**AutoGraph**: rewrites Python control flow into TF graph ops (Ch 12, App D)
**Autoencoder**: encoder + decoder trained to reconstruct inputs through constrained codings (Ch 17)
**Backpropagation**: forward pass, then reverse-mode autodiff of the loss, then a gradient descent step (Ch 10, App B)
**Bagging / pasting**: ensemble trained on random subsets with / without replacement (Ch 7)
**Batch normalization**: normalize layer inputs per mini-batch, then scale (γ) and shift (β); moving averages at test time (Ch 11)
**Beam search**: keep the top-k partial sequences during decoding (Ch 16)
**Bias/variance trade-off**: generalization error = bias + variance + irreducible error (Ch 4)
**BIC / AIC**: information criteria penalizing parameters, for GMM selection (Ch 9)
**Callback (Keras)**: hook run during training: ModelCheckpoint, EarlyStopping, TensorBoard, ReduceLROnPlateau (Ch 10–11)
**CART**: greedy binary-split tree algorithm minimizing weighted impurity/MSE (Ch 6)
**Causal model / padding**: output at t depends only on inputs ≤ t (Ch 15–16)
**Concrete function**: graph specialized for one input signature of a TF Function (App D)
**Confusion matrix**: counts of actual (rows) × predicted (columns) classes (Ch 3)
**Cross-validation (k-fold)**: train on k−1 folds, evaluate on the remaining fold, repeat k times (Ch 2)
**Cross entropy / log loss**: −Σ y log p̂; loss for classification (Ch 4)
**Curse of dimensionality**: high-D spaces are sparse, so extrapolation and overfitting rise (Ch 8)
**Data augmentation**: generate realistic variants of training instances (Ch 14)
**Data mismatch**: training data unlike production data; diagnose with a train-dev set (Ch 1)
**Data parallelism / model parallelism**: replicate the model across devices vs split it across devices (Ch 19)
**DBSCAN**: density-based clustering via core instances (eps, min_samples) (Ch 9)
**Diffusion model (DDPM)**: learns to predict and remove noise step by step; generates from pure noise (Ch 17)
**Dropout / MC dropout**: randomly zero neurons in training / average stochastic passes at inference for uncertainty (Ch 11)
**DQN**: neural Q-value approximator with replay buffer and target network (Ch 18)
**Early stopping**: stop training when validation error is at its minimum (Ch 4, 10)
**Embedding**: trainable dense vector per category/token (Ch 13, 16)
**Encoder–decoder**: seq-to-vector encoder feeding a vector-to-seq decoder (Ch 15–16)
**Epoch**: one full pass over the training set (Ch 4)
**ε-greedy**: random action with probability ε, else greedy (Ch 18)
**Explained variance ratio**: fraction of variance along each principal component (Ch 8)
**F1 score**: harmonic mean of precision and recall (Ch 3)
**FCN (fully convolutional network)**: dense layers replaced by convs; any input size (Ch 14)
**Feature map / filter (kernel)**: output of / weights shared by a conv layer's neurons (Ch 14)
**GAN**: generator vs discriminator trained adversarially (Ch 17)
**Gaussian mixture model**: data as a mixture of Gaussians, fit by EM (Ch 9)
**Gini impurity / entropy**: node impurity measures for trees (Ch 6)
**Glorot / He / LeCun initialization**: variance-scaled inits matched to activations (Ch 11)
**Gradient clipping**: cap gradient values/norm, mainly for RNNs (Ch 11)
**Gradient descent (batch / stochastic / mini-batch)**: iterative cost minimization along −∇ (Ch 4)
**GradientTape**: TF context that records ops for autodiff (Ch 12)
**GRU / LSTM**: gated recurrent cells with long-term memory (Ch 15)
**Hinge loss**: max(0, 1 − t·s); linear SVM loss (Ch 5)
**Huber loss**: quadratic for small errors, linear for large; robust to outliers (Ch 10, 12)
**Hyperparameter**: setting of the learning algorithm, fixed before training (Ch 1)
**Imputation**: filling missing values (median, kNN, iterative) (Ch 2)
**Inertia**: sum of squared distances to the nearest centroid (Ch 9)
**IoU / mAP**: box overlap ratio / mean average precision for detection (Ch 14)
**Kernel trick**: compute high-D dot products without the mapping, via the dual problem (Ch 5)
**k-means / k-means++**: centroid clustering / smart distant-centroid initialization (Ch 9)
**Label propagation**: spread representative labels to cluster members (Ch 9)
**Layer normalization**: normalize across features per instance; used in RNNs and transformers (Ch 15–16)
**Learning curves**: train/validation error vs training size or iterations (Ch 4)
**Learning rate / schedule**: GD step size / its evolution (power, exponential, piecewise, performance, 1cycle) (Ch 4, 11)
**Lasso / Ridge / Elastic Net**: ℓ1 / ℓ2 / mixed regularized linear regression (Ch 4)
**Masking**: ignore padding tokens in sequence models (Ch 16)
**MDP**: states, actions, transition probabilities, rewards (Ch 18)
**Mode collapse**: GAN generator producing little diversity (Ch 17)
**Multi-head attention**: parallel scaled dot-product attentions over different projections (Ch 16)
**Nesterov accelerated gradient**: momentum with look-ahead gradient (Ch 11)
**No Free Lunch theorem**: no model is a priori best without assumptions (Ch 1)
**Normal equation**: closed-form linear regression θ = (XᵀX)⁻¹Xᵀy (Ch 4)
**OOB evaluation**: validate bagged predictors on the ~37% unsampled instances (Ch 7)
**OvR / OvO**: one-vs-rest / one-vs-one multiclass strategies (Ch 3)
**Overfitting / underfitting**: model too complex / too simple for the data (Ch 1, 4)
**PCA**: project onto axes of maximum variance (SVD) (Ch 8)
**Pipeline / ColumnTransformer**: chained or per-column Scikit-Learn transformations (Ch 2)
**Policy gradient (REINFORCE)**: raise the probability of actions with positive advantage (Ch 18)
**Positional encoding**: vector added to embeddings to encode token position (Ch 16)
**Precision / recall**: TP/(TP+FP) / TP/(TP+FN) (Ch 3)
**Prefetch**: prepare next batches on the CPU while the GPU trains (Ch 13)
**Q-learning / Q-value**: off-policy TD learning of expected return per state-action (Ch 18)
**Quantization (post-training)**: float32 → int8 weights for TFLite (Ch 19)
**Random forest / Extra-Trees**: bagged trees with random feature subsets / random thresholds (Ch 7)
**Random projection / JL lemma**: distance-preserving random linear projection; minimum dims (Ch 8)
**Regularization**: constraining a model to reduce overfitting (Ch 1, 4, 11)
**Replay buffer**: memory of past experiences sampled for DQN training (Ch 18)
**Residual (skip) connection**: add inputs to outputs, h(x) = f(x) + x (Ch 14)
**RMSE / MAE / MAPE**: regression and forecast error metrics (Ch 2, 15)
**ROC curve / AUC**: TPR vs FPR across thresholds / area under it (Ch 3)
**SARIMA**: seasonal ARIMA time series model (Ch 15)
**SavedModel**: TF's versioned export format (graph + weights + signatures) (Ch 10, 19)
**Silhouette score**: (b − a)/max(a, b) cluster quality (Ch 9)
**Softmax regression**: multinomial logistic regression (Ch 4)
**Stacking**: blender trained on out-of-fold base predictions (Ch 7)
**Stateful RNN**: keeps hidden state across batches (Ch 16)
**Stratified sampling**: preserve strata proportions in splits (Ch 2)
**Support vectors**: instances on or inside the SVM margin (Ch 5)
**Temperature (sampling)**: logits scaling controlling generation diversity (Ch 16)
**TF Function / tracing**: Python function compiled to a graph per input signature (Ch 12, App D)
**TF-IDF**: term frequency × inverse document frequency weighting (Ch 13)
**TFRecord / protobuf (Example)**: TF's binary record format / serialized feature maps (Ch 13)
**Transfer learning**: reuse pretrained layers for a new task (Ch 11, 14)
**Transformer**: attention-only encoder–decoder architecture (Ch 16)
**VAE**: autoencoder with Gaussian latent sampling + KL latent loss (Ch 17)
**Weight decay**: shrink weights each step (AdamW) (Ch 11)
